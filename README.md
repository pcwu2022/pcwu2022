## 🚀 Featured Projects

### 🐱 [Whiskers IDE](https://github.com/pcwu2022/scratch_compiler)
A web-based IDE that bridges Scratch-style block coding to real JavaScript syntax — built to help young learners cross the gap between drag-and-drop logic and text-based programming, with a full Monaco Editor, multi-sprite support, and instant browser preview.

### 🏙️ [Urban Radius](https://github.com/pcwu2022/urban_radius/)
An original algorithm — derived conceptually from the academic H-Index — for measuring a city's "true" functional size without relying on arbitrary administrative borders. Includes an interactive simulation site to explore how the calculated boundaries shift with different parameters.

### 🌌 [Acquired Universe](https://github.com/pcwu2022/acquired_universe/)
A space-time graphical explorer of the companies covered on the *Acquired* podcast, with a chronological time-lapse view, a company connection graph sourced from episode captions, and per-company event timelines.

### 💑 [NTU Pair](https://github.com/pcwu2022/ntupair_readonly)
A full-stack dating app built from scratch (vanilla JS) that used psychological-compatibility matching instead of swiping, reaching 1,600+ verified NTU student users. After facing real-world XSS, DoS, and credential-stuffing attempts, I re-architected the system around secure coding practices.

### 🔄 [LifeOS Automation System](https://github.com/cubee-chen/pinecraft-notion-auto)
A Python service (team of 7) synchronizing a team's Notion workspace with MongoDB, built around a four-state version model (`UP_TO_DATE`, `AHEAD`, `BEHIND`, `NOT_TRACKED`) and a canonical document-mapping architecture for one-to-many schedule synchronization.
[Code](https://github.com/cubee-chen/pinecraft-notion-auto)

### 🖼️ [Obamify](https://github.com/pcwu2022/obamify)
A pixel-swap image transformation algorithm implemented in SystemVerilog on FPGA, verified against a Python cycle-accurate architectural reference model.

### 🔍 [Reverse Engineering](https://github.com/pcwu2022/ieda_reverse_engineering)
A Python toolkit exploring BDD/BMD-based formal methods, Graph Neural Networks, and LLM-assisted prompting to reconstruct arithmetic RTL from gate-level circuits, referencing the 2022 ICCAD contest.

### 🖥️ [CPU Design](https://github.com/pcwu2022/ca_cpu_final)
A 32-bit RISC-V multi-cycle processor with a 32-block direct-mapped write-through cache, achieving a 50% speedup and ranking in the top 15% of the class.

### 🦎 [Robotic Chameleon — Cockroach Catcher (🥇 Silicon Motion Corporate Award, MakeNTU 2025)](https://github.com/YBA857142/2025MakeNTU)
A computer-vision-guided robotic chameleon that tracks and catches cockroaches via a Raspberry Pi, perspective-transformed coordinates, and a PID controller, built in 24 hours.

### 🪖 [HelpMet — AR Navigation Helmet (🏆 Best Maker Award, MakeNTU 2024)](https://github.com/pcwu2022/bjtburger)
An AR navigation assistant mounted inside a motorcycle helmet using speech recognition and a multi-threaded, flip-flop-inspired architecture to synchronize asynchronous voice, API, and display modules in real time.

### 🏥 [SLEKMED — Medical Diagnosis Simulation Systems](https://slek-system.vercel.app/projects/hyponatremia)
Product developer on two teaching-aid platforms: a Hyponatremia diagnosis simulator (funded by Taiwan's Ministry of Education) and an AI-driven Online Hospital simulation system that won 1st place among 40+ teams at the 2024 CTCI AI Competition.

## 🔬 Research

- **In Search of the Smallest Vocabulary Set Using Formal Methods** — modeled optimal vocabulary-learning sequencing as an NP-hard Target Set Selection variant, solved via Bounded Model Checking, Interpolation-Based Unbounded Model Checking, and Property-Directed Reachability. *(Advisor: Prof. Chung-Yang (Ric) Huang, NTU)*
- **SAR ADC and PLL Design** — MATLAB simulations across five SAR ADC topologies (conventional, monotonic-switching, split-capacitor, merge-switched, redundant-capacitor), plus study of PLLs and CTLE/FFE design for SerDes front-ends. *(Advisor: Prof. Tai-Cheng Lee, NTU)*
- **The Impact of Quantum Computing on Cryptocurrencies** — analyzed ECDSA attack vectors (Pollard's Rho, quantum ECDLP solvers) and surveyed post-quantum signature schemes.
- **Separation and Transfer of Monolayer MoS₂** — high-school research at NSRRC on UV/thermal/ultrasonic-assisted separation and transfer of monolayer Molybdenum Disulfide. *(Advisor: Prof. Chia-Hao Chen, NSRRC)*
